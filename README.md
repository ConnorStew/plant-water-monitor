# Raspberry-Pi-GPIO

## Commands

Push:
```bash
scp ./gpio.py ./requirements.txt connor@192.168.4.56:~/gpio
```

Run:
```bash
ssh connor@192.168.4.56
source ./venv/bin/activate
python gpio.py
```

## Setup

- Using a raspberry pi 1, the pins are in shown in the attached board image.
